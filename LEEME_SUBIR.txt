LISTO PARA SUBIR
El archivo index.html está en la raíz de este ZIP. No añadas una carpeta exterior.

CLOUDFLARE PAGES
1. Inicia sesión en https://dash.cloudflare.com/.
2. Abre Workers & Pages y crea una aplicación de Pages.
3. Elige cargar archivos y arrastra este ZIP directamente.
4. Escribe el nombre del proyecto y publica.
5. Abre el enlace terminado en .pages.dev y revisa Inicio, Proyectos, CV y WhatsApp.

HOSTING CON CPANEL
Sube este ZIP a public_html y extráelo allí. Comprueba que public_html/index.html existe.
Para actualizar, reemplaza el contenido anterior por los archivos de este paquete.

EN TU COMPUTADORA
Extrae todo el ZIP y abre index.html. Conserva juntas las carpetas assets, css, js, docs y proyectos.

QUÉ INCLUYE
Portafolio, 6 casos de proyecto, demos locales, CV web, CV en PDF y página 404.
Escena 3D de portada creada para este portafolio; el logo original se superpone de forma independiente.

INTERACCIÓN
Con ratón, la portada y las tarjetas responden al cursor. En móvil se conserva el volumen sin interferir con el desplazamiento táctil. La preferencia de reducir movimiento se respeta.
